API Keys

API keys are used to authenticate requests to the Nexus /v1 API. Anyone holding this key can call your endpoint — keep it like a password.

Every project can hold its own key. Disabling a key stops it immediately without touching the others; deleting removes it for good — anything still using it (like DSRclone) stops connecting. Keys are stored encrypted on the server and sync like your friend list, so they survive restarts.

Supply lanes

Nexus as an OpenAI-compatible endpoint for your other projects — requests are answered by the same provider lanes as Nexus chat, with failover: the relay key set first, then the FreeLLMAPI providers. Ask for model nexus-auto and Nexus tries the lanes in this order until one answers. A specific lane model can be requested as lane/model, e.g. relay_groq/openai/gpt-oss-20b. GET /v1/models lists everything currently reachable.
